# Простейший компилятор чисел

Компилятор принимает файл с одним числом от `0` до `255` и генерирует `x86_64` assembler.

Число становится кодом возврата программы.

## Запуск

### 1. Сгенерировать assembler
```shell
python3 compiler.py test01.lang test01.s
```

### 2. Собрать объектный файл
```shell
nasm -f elf64 test01.s -o test01.o
```

### 3. Собрать исполняемый файл
```shell
ld test01.o -o test01
```

### 4. Запустить и посмотреть результат
```shell
./test01
echo $?
```

Должно вывести число из файла:
```shell
42
```

Допустимы только целые числа `0-255`.
