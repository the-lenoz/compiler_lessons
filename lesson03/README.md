# Арифметика: +, -, *, / и скобки

Компилятор принимает файл с арифметическим выражением и генерирует ассемблер.

Результат вычисления становится кодом возврата программы.

Поддерживаются операции `+`, `-`, `*`, `/`, скобки `()` и приоритет операций.

## Запуск

### 1. Сгенерировать assembler
```shell
python3 compiler.py test01.lang test01.s
```

### 2. Собрать объектный файл
```shell
nasm -f elf64 test01.s -o test01.o
```

### 3. Собрать исполняемый файл
```shell
ld test01.o -o test01
```

### 4. Запустить и посмотреть результат
```shell
./test01
echo $?
```

Должно вывести:
```shell
55
```
