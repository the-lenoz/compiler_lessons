# Функции и вызовы

Компилятор принимает файл с функциями и генерирует ассемблер.

Поддерживаются объявления и определения функций, аргументы, вызовы и рекурсия. Выполнение программы начинается с функции `main`.

## Запуск

### 1. Сгенерировать assembler
```shell
python3 compiler.py test01.lang test01.s
```

### 2. Собрать объектный файл
```shell
nasm -f elf64 test01.s -o test01.o
```

### 3. Собрать исполняемый файл
```shell
ld test01.o -o test01
```

### 4. Запустить и посмотреть результат
```shell
./test01
echo $?
```

Пример выведет сначала "Hello, world!", а затем 14-е число Фибоначчи: `377`. Код возврата ограничен диапазоном `0-255`, поэтому должно вывести `377 % 256`:
```shell
121
```
