# Условия и циклы

Компилятор принимает файл с программой и генерирует код.

Помимо арифметики и переменных, поддерживаются операторы сравнения (`==`, `<`, `>`, `<=`, `>=`), условный переход `if (cond) { ... }` и цикл `while (cond) { ... }`.

## Запуск

### 1. Сгенерировать assembler
```shell
python3 compiler.py test01.lang test01.s
```

### 2. Собрать объектный файл
```shell
nasm -f elf64 test01.s -o test01.o
```

### 3. Собрать исполняемый файл
```shell
ld test01.o -o test01
```

### 4. Запустить и посмотреть результат
```shell
./test01
echo $?
```

Должно вывести 7-е число Фибоначчи:
```shell
13
```
